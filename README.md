# 🎓 CampusAI – Smart College Portal

An AI-powered college portal for students, professors, and parents.

## ✨ Features
- AI Chatbot
- Smart Dashboard
- Departments & Courses
- Faculty Information
- Semester-wise Syllabus
- Professor Syllabus Management
- Notices & Events
- Previous GTU Papers
- AI Syllabus Planner
- Student Support

## 🛠️ Tech Stack
- React.js & Vite
- Node.js & Express.js
- MongoDB & Mongoose
- OpenRouter API
- Cloudinary
- JWT Authentication
